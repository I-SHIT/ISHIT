## 我是管理员

### 1. 环境要求
- **Node.js**：建议使用 `Node.js >= 18`
- **NapCat（可选）**：如需开启 QQ 群聊/私聊签到通知及群内二维码图片自动识别，需配合 NapCat 使用

### 2. 安装与启动
```bash
# 1. 进入项目目录并安装依赖
npm install

# 2. 启动服务（默认监听 8080 端口）
npm start
```
如需自定义监听端口，可通过环境变量指定（例如 PowerShell）：
```powershell
$env:PORT=8080; npm start
```

### 3. 登录面板与基础配置
1. 浏览器访问 `http://127.0.0.1:8080`。
2. 使用初始管理员账号登录控制面板：
   - **初始账号**：`ishit`
   - **初始密码**：`ishit2026`
   - 登录后请第一时间前往 **系统设置 -> 用户管理** 修改默认密码，或按需创建普通用户（`User`）。
3. **绑定XXX账号**：进入 **系统设置 -> XXX账号**，支持账号密码、手机验证码、二维码扫码或生成协助链接登录。
4. **配置课程与课表**：进入 **账号工作台** 同步课程与课表，按需 DIY 排课、单课预设位置、拍照图库。
5. **配置轮询策略**：进入 **系统设置 -> 轮询** 设置课表轮询开关、扫描间隔以及防钓鱼等设置。

### 客户端离线模式

在登录页或系统设置的「用户与权限」页切换模式。离线模式自动建立本地管理员实例，使用与在线模式相同的仪表盘、账号工作台、签到悬赏和系统设置。学习通账号需在本机绑定，支持密码、短信与二维码登录。课程、课表、位置及图片预设、签到记录、NapCat 配置和 Cookie 均保存在客户端 IndexedDB 数据库中。

Windows 和 Android 客户端通过原生网络层直接请求学习通。课表轮询和自动签到仅在客户端处于前台时运行，切入后台暂停并取消在途请求，回到前台恢复。离线模式仍需连接网络以访问学习通。

在「签到悬赏」中粘贴分享链接可读取活动并使用本机绑定的课程账号处理。离线模式生成的分享链接携带活动信息，其他客户端可直接导入。在线服务生成的 token 链接需其来源服务在线才能读取。

「用户与权限」中的导入导出包含全部本地账号凭据、Cookie、课表、配置、记录和上传的留言图片。导入前校验格式，确认后一次性替换本机数据。备份含登录凭据，请妥善保管。在线模式的面板登录会话保留在原设备，切换模式可继续使用。0.2.0 的离线课表会迁移到「旧版本地课表」账号，可将排课复制给新绑定的学习通账号。

构建客户端前安装开发依赖，运行 `npm run build:local` 生成与后端源码一致的本地引擎。Windows 和 Android 构建脚本会自动执行此步骤。可用 `node --test test/timetable.test.js`、`node test/local-client.cjs` 和 `node test/windows-local.cjs` 验证课表约束、完整本地链路和 Windows 原生网络层，后两项需要 Microsoft Edge。

### 4. NapCat 插件联动配置（可选）
1. 将 Bridge 插件文件夹（`napcat-plugin-qce`）放入 NapCat 的 `plugins/` 目录。
2. 在 NapCat 的 `config/plugins.json` 中启用插件（`"napcat-plugin-qce": true`）并重启 NapCat。
3. 在 ISHIT 面板进入 **系统设置 -> NapCat 推送**，填入插件接口地址、公网/局域网访问地址以及目标群号（支持按用户进行提醒 `@QQ`）。

### 5. 数据持久化说明
- 所有账号凭据、Cookie、课表及系统配置均保存在 `data/store.json` 中（已在 `.gitignore` 忽略，请勿上传至公开仓库）。迁移服务器时只需复制 `data/store.json` 即可无缝恢复全部配置。
