## 我是管理员

### 1. 环境要求
- **Node.js**：建议使用 `Node.js >= 18`
- **NapCat（可选）**：如需开启 QQ 群聊/私聊签到通知及群内二维码图片自动识别，需配合 NapCat 使用

### 2. 安装与启动
```bash
# 1. 进入项目目录并安装依赖
npm install

# 2. 启动服务（默认监听 8080 端口）
npm start
```
如需自定义监听端口，可通过环境变量指定（例如 PowerShell）：
```powershell
$env:PORT=8080; npm start
```

### 3. 登录面板与基础配置
1. 浏览器访问 `http://127.0.0.1:8080`。
2. 使用初始管理员账号登录控制面板：
   - **初始账号**：`ishit`
   - **初始密码**：`ishit2026`
   - 登录后请第一时间前往 **系统设置 -> 用户管理** 修改默认密码，或按需创建普通用户（`User`）。
3. **绑定XXX账号**：进入 **系统设置 -> XXX账号**，支持账号密码、手机验证码、二维码扫码或生成协助链接登录。
4. **配置课程与课表**：进入 **账号工作台** 同步课程与课表，按需 DIY 排课、单课预设位置、拍照图库或测试课程。
5. **配置轮询策略**：进入 **系统设置 -> 轮询** 设置课表轮询 / 持续轮询模式、扫描间隔以及防钓鱼等设置。

### 4. NapCat 插件联动配置（可选）
1. 将 Bridge 插件文件夹（`napcat-plugin-qce`）放入 NapCat 的 `plugins/` 目录。
2. 在 NapCat 的 `config/plugins.json` 中启用插件（`"napcat-plugin-qce": true`）并重启 NapCat。
3. 在 ISHIT 面板进入 **系统设置 -> NapCat 推送**，填入插件接口地址、公网/局域网访问地址以及目标群号（支持按用户进行提醒 `@QQ`）。

### 5. 数据持久化说明
- 所有账号凭据、Cookie、课表及系统配置均保存在 `data/store.json` 中（已在 `.gitignore` 忽略，请勿上传至公开仓库）。迁移服务器时只需复制 `data/store.json` 即可无缝恢复全部配置。
